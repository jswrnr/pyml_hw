# Assignment 1: _Python Playground_

This assignment provides you all with the opportunity to become familiar with Python and become familiar with some ideas from ML along the way. 

Each file, or puzzle, contains functions for you all to fill out. Sometimes they are related or rely on each other. Sometimes they are independent from each other.  

The puzzles increase in difficulty as you go higher in the alphabetic index. So `a_foobar.py` is the easiest and `i_linalg.py` is the most difficult. It should be noted that you don't have to be able to answer _all_ of these questions to do well in the rest of this course, but you should be able to do most of them with a good bit of thought and effort. 

Be sure to run `make install` to instantiate the virtual environment. Running `make` alone will display the help message, which lists all of the commands in the Makefile. 

Be sure to use `git`, and to submit your results **EARLY** and **OFTEN**! :D
